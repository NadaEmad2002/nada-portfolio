## Deploy (GitHub Pages)
1. github.com -> New repository named `nada-portfolio` (Public).
2. Upload everything in this folder (keep the `assets` folder).
3. Settings -> Pages -> Source: "Deploy from a branch" -> main / (root) -> Save.
4. After ~1 minute the site is live at https://nadaemad2002.github.io/nada-portfolio/
5. If your URL differs, run: python make_qr.py https://YOUR-URL/

## Update later
- New CV/infographic: replace the PDF in `assets/` keeping the SAME file name. The QR never changes.
- LinkedIn link: edit the `href` of the LinkedIn button in index.html.
